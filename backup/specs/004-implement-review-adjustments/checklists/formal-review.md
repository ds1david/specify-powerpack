# Checklist: Formal Review Enforcement

- [ ] Any accepted finding against the selected target is blocking until resolved.
- [ ] Remaining accepted findings produce formal `REQUEST_CHANGES` when GitHub review submission is available.
- [ ] Severity is diagnostic only and never an approval threshold.
- [ ] Findings are not converted into technical debt or future work to obtain approval.
- [ ] Findings requiring work are materialized in `tasks.md` and applicable checklists/authoritative artifacts.
- [ ] All materialized work is implemented and revalidated before closure.
- [ ] Final approval is issued only after a fresh zero-finding review of the current snapshot.
